⛳ گلف ویژن استودیو

نمونه‌ی عملیِ فناوری‌های هسته‌ی اپ‌های حرفه‌ای گلف — ردیابی توپ (Shot Tracer)، ضبط خودکار ضربه (Swing Profile)، اسکلت بدن (Sportsbox) و فیزیک خواندن گرین (PuttView) — همه‌ی پردازش‌ها داخل مرورگر تو انجام می‌شود.

    📜 گزارش رویدادها

      🧭 اپ‌هایی مثل PuttView X و PuttArc اول با LiDAR آیفون نقشه‌ی ارتفاعی گرین را اسکن می‌کنند، بعد گرادیان شیب را حساب می‌کنند و در آخر دقیقاً همین فیزیک غلتش توپ را روی آن نقشه اجرا می‌کنند تا «خط ایده‌آل» و «نقطه‌ی نشانه‌گیری» را روی چمن نمایش دهند. اینجا همان حل‌کننده‌ی فیزیک را می‌بینی — فقط شیب را دستی به‌جای LiDAR می‌دهی.

      🧪 گزارش حل‌کننده

      فلش‌های آبی روی زمین جهت «پایین‌دستی شیب» را نشان می‌دهند — همان Slope Arrows معروف PuttView. سرعت ضربه اولیه خودکار انتخاب می‌شود (متناسب با فاصله).

      🧠 هر اپ حرفه‌ای گلف با چه تکنولوژی‌ای ساخته شده؟

      ✨ ردیابی توپ — Shot Tracer / Ace Trace

      جداسازی «لکه‌ی روشن» (bright-blob segmentation) + پیش‌بینی حرکت با فیلتر کالمن + جریان نوری (optical flow) برای فریم‌های مبهم. خروجی: خط ترِیسر تلویزیونی + افکت استروب برای پات. کاملاً روی دستگاه و آفلاین.

      🤖 ضبط خودکار — Swing Profile / OnForm

      تشخیص حرکت با تفاضل فریم (frame differencing) روی جریان زنده‌ی دوربین؛ وقتی انرژی حرکت از آستانه بگذرد ضبط شروع می‌شود و بعد از سکون قطع. دوربین ثابت + هیچ سنسوری لازم نیست.

      🦴 اسکلت و بیومکانیک — Sportsbox AI / DeepSwing

      شبکه‌ی عصبی تخمین پوز (Pose Estimation) مثل MediaPipe/BLAZEPOSE با ۳۳ نقطه‌ی بدن، بعد مدل ۲بعدی→۳بعدی (lifting به اسکلت SMPL) برای زوایای واقعی بیومکانیک. اجرا روی تراشه‌ی گوشی (CoreML/NNAPI).

      🧭 اسکن AR گرین — PuttView X / PuttArc / GolfScope

      سنسور LiDAR + ARKit (Scene Reconstruction) → مش سه‌بعدی و نقشه‌ی ارتفاع گرین → گرادیان شیب → فیزیک غلتش توپ (اصطکاک بر اساس Stimp) → رندر خط پات با RealityKit. نیاز به iPhone Pro؛ اندروید معادلش ARCore Depth API است.

      📡 سنسورها — Blast / HackMotion / Arccos

      سخت‌افزار IMU (شتاب‌سنج + ژیروسکوپ) با بلوتوث: تمپو، چرخش فیس، زاویه مچ. Arccos سنسور روی گریپ + GPS برای ثبت خودکار ضربه‌ها در زمین.

      🎥 شبیه‌ساز پات — Exputt RG

      دوربین سرعت‌بالا (high-speed) + مارکر روی پاتر؛ بینایی ماشین زاویه‌ی فیس، مسیر و تمپو را می‌خواند و روی گرین مجازی تلویزیون نمایش می‌دهد.
      قابلیتدر وب (همین صفحه)در اپ موبایل حرفه‌ای
      ردیابی توپ و ترِیسر✅ کامل (موتور همین صفحه)✅ با فریم‌ریت بالاتر (240fps)
      ضبط خودکار ضربه✅ کامل✅ کامل + بافر حلقه‌ای
      اسکلت بدن ۲بعدی✅ با اینترنت (MediaPipe)✅ آفلاین روی تراشه
      بیومکانیک ۳بعدی⛔ سنگین است✅ مدل lifting + SMPL
      اسکن AR گرین⛔ نیاز به LiDAR/ARKit✅ فقط iPhone Pro / پروژکتور
      دیتای سنسوری IMU⛔✅ سخت‌افزار جانبی
      🚀 مسیر ساخت نسخه‌ی موبایل کامل: پوسته‌ی بومی (Swift برای iOS / Kotlin برای اندروید) یا Flutter + «MediaPipe Tasks Vision» برای اسکلت + ARKit RealityKit و SceneReconstruction برای اسکن گرین + AVFoundation/Camera2 برای ضبط ۲۴۰ فریم. همین منطق‌هایی که اینجا در جاوااسکریپت دیدی، عیناً به آن پلتفرم‌ها قابل انتقال است.
      ساخته‌شده به‌عنوان نمونه‌ی فناوری — تمام پردازش‌ها داخل مرورگر تو اجرا می‌شود و هیچ ویدیویی جایی آپلود نمی‌شود. برای دوربین زنده و دانلود خروجی، فایل را دانلود و در کروم باز کن.
